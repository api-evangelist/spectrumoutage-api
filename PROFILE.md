# SpectrumOutage API

Community-powered REST API for live Spectrum internet, TV, and phone outage data across the US. Independent tracker, not affiliated with Charter Communications or Spectrum. Provides aggregate stats, outage reports, city/state/ZIP status, and map pin data.

## APIs

- **SpectrumOutage API v1** — REST API for live Spectrum internet, TV, and phone outage data across the US. Bearer API key required on all endpoints. Endpoints include /stats, /reports, /cities/{slug}, /states, /zip/{zip}, and /map. (`https://spectrumoutage.us/api/v1`)
